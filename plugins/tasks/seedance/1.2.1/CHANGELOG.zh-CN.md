# Changelog

## [1.2.1]

### Changed

- 公开模型广场上的定价元数据改用与 Doubao 插件一致的终端用户措辞：计费因子显示为「计费 Token 单价」「输出视频时长（秒）」「输出视频分辨率」「参考视频输入」，定价示例显示为「720p · 5s」这类纯档位标签。

### Fixed

- 模型广场定价页不再显示插件内部的能力说明。网关自定义模型名（渠道映射别名，如 `wux-dance-2-0`）解析到插件的默认计费元数据，旧文案会提到上游网关名族与内部模型档位名；模型广场访客现在只会看到面向终端用户的措辞。
